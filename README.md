# Tecnologia para o Impacto Social

Três protótipos acadêmicos em Python com Programação Orientada a Objetos.

## Projetos
- `prato_cheio/`: doações de alimentos (ODS 2).
- `olho_dagua/`: registro de vazamentos (ODS 6).
- `ecoponto/`: coleta de resíduos eletrônicos (ODS 12).

## Execução
Entre na pasta de cada projeto e execute `python main.py`.

## Diagramas
Os diagramas UML estão na pasta `diagramas/`.

## Requisitos
Python 3.9 ou superior. Sem bibliotecas externas para executar os protótipos.

## Escopo
Protótipos didáticos de console; não são sistemas de produção.
