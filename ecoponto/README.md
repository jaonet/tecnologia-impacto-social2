# EcoPonto

Sistema para registrar a entrega de resíduos eletrônicos em pontos de coleta. O cidadão informa o tipo e o peso do material; o sistema calcula pontos de incentivo e registra a destinação correta.

## ODS
ODS 12 — Consumo e Produção Responsáveis; também contribui para o ODS 11 — Cidades e Comunidades Sustentáveis.

## Como executar
Requisito: Python 3.9 ou superior. Não há dependências externas.

```bash
python main.py
```

## Conceitos de POO
- Classes e objetos: entidades do domínio são representadas por classes.
- Encapsulamento: atributos internos são protegidos por convenção e atualizados por métodos.
- Herança e polimorfismo: classes especializadas herdam de uma classe base e implementam operações específicas.
- Relacionamentos: associações e relações de composição/agregação representam as ligações do domínio.

## Observação
Este é um protótipo acadêmico executado no terminal. Em uma versão de produção, seriam necessários banco de dados, autenticação real, interface e validações adicionais.
